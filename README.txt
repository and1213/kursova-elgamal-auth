Програмний макет підсистеми ідентифікації та автентифікації користувачів
Курсова робота з дисципліни «Основи інформаційної безпеки»
Колесник В. Є., група К23-3. Варіант (В, К): N = 8, S = 3, F(x) = lg(4x), T = 10 хв,
R = 64 десяткові знаки, алгоритм ElGamal.

ЗАПУСК
  Потрібен Python 3.8 або новіший з модулем tkinter (у Windows встановлюється
  разом з Python з python.org за замовчуванням). Сторонні бібліотеки не потрібні.

  python main.py          звичайний режим, рукостискання кожні T = 10 хв
  python main.py --demo   демонстраційний режим, рукостискання щохвилини
  python tests.py         автоматична перевірка на контрольних прикладах
  python test_speed.py    вимірювання швидкодії ElGamal (R = 32, 64, 96, 128)

ОБЛІКОВІ ЗАПИСИ (демонстраційні дані в data/nameuser.txt)
  admin  / Adm1n#2026   адміністратор (реєстрація та видалення користувачів)
  ivan   / Qwerty12     A: R,E   B: R,E,A   D: R          (середній рівень)
  olena  / sonechko     усі диски E,R,W,A, пароль діє 14 діб (максимальний рівень)
  petro  / Tr0yanda#2   A: R   C: E                         (мінімальний рівень)
  taras  / Tar@s_2026   A: R                                (мінімальний рівень)

  Щоб почати з чистого стану, видаліть каталоги data і disks: під час наступного
  запуску буде створено лише обліковий запис admin / Adm1n#2026.

ВІДПОВІДЬ НА ЗАПИТ РУКОСТИСКАННЯ
  Y = lg(4·X) з точністю до 0,001 (кома або крапка), наприклад X = 10 -> 1,602.

ФАЙЛИ
  data/nameuser.txt  реєстраційний журнал (ім'я|пароль|права|дата|строк дії)
  data/us_book.txt   операційний журнал дій користувачів
  data/ask.txt       запитання X для рукостискання
  data/input.txt     службове повідомлення для шифрування
  data/close.txt     шифротекст (пари a b)
  data/out.txt       розшифрований текст
  data/keys.txt      ключі ElGamal (p, g, y, x)
  disks/A ... disks/E  каталоги, що імітують логічні диски
